# LINE 溫和口吻文案

2026/11/19 更新。依使用者確認的口吻修改，本次僅提交 LINE 文案與相關測試，不包含尚待驗收的首頁及研究資料介面改版。GitHub 推送與 Supabase 函式部署是分開的；僅推送 GitHub 不會讓官方 LINE 改用新文案。

## 範圍與規則

- 09:00 使用「早安～昨天睡得好嗎？」；11:00–21:00 的後續時段使用「小小提醒～」，晚上不說早安。
- 綁定／重新確認／取消確認與完成、帳密核對失敗、服務連線失敗改為溫和說明。
- 保留研究帳號、日誌日期、首次正式提醒日期及既有按鈕／個人連結。
- 保留隔日 09:00 起、未填每兩小時提醒、正式提交後當日停發、確認取消後停發及一對一綁定。
- 手錶同步只是一段提醒文字，不新增停發條件，不宣稱系統已確認上傳手錶資料。
- 綁定成功僅在官方成功 callback 後顯示；連結尚未開放時不提供失效按鈕。
- 此次僅更新文案，不變更綁定資料、排程、Cron、訊息配額或既有重試佇列；沒有發真實 LINE。

## 可複製範例

下列帳號與日期只作格式示例，實際訊息會依綁定與排程代入，沒有放入任何個人 capability／token。

### 1. 早上 09:00 提醒

```text
早安～昨天睡得好嗎？
有空時，記得動動手指，同步上傳手錶資料，並填寫線上睡眠日誌喔～
謝謝你的協助，祝你有個美好的一天！
研究帳號：ycc00000050
日誌日期：2026/11/19
```

### 2. 當天後續提醒

```text
小小提醒～今天的睡眠日誌還沒完成喔。
如果現在方便，可以點下方連結，記錄昨晚的睡眠狀況。
謝謝你撥空協助研究～
研究帳號：ycc00000050
日誌日期：2026/11/19
```

### 3. 開始綁定

```text
歡迎使用睡眠日誌小幫手～
請點下方按鈕，輸入研究團隊提供的 Docter+ 帳號與密碼。
完成綁定後，就能收到自己的日誌連結囉！
```

### 4. 綁定成功與個人日誌測試

```text
已幫你完成綁定囉～
研究帳號：ycc00000050
【日誌連結測試】先點下方按鈕，確認能否開啟自己的睡眠日誌。
日誌日期：2026/11/19
首次正式提醒：2026/11/20 09:00
謝謝你的參與！
```

### 5. 重新綁定／已有綁定

```text
目前綁定的研究帳號是 ycc00000050 囉～
同帳號可點下方按鈕重新確認；想更換研究帳號，請先取消目前的綁定，再綁定新的帳號喔～
```

### 6. 確認取消綁定

```text
要取消研究帳號 ycc00000050 的綁定嗎？
取消後會停止後續填寫提醒，已經填好的日誌會保留，請放心。
之後有需要，也可以再次綁定～
```

### 7. 取消綁定完成

```text
已幫你取消綁定，後續填寫提醒也已停止囉。
已經填好的日誌會保留，謝謝這段時間的協助！
之後需要使用時，點「開始綁定」就可以了～
```

### 8. 帳號或密碼核對失敗

```text
這次還沒核對成功，請再確認一下研究帳號與密碼喔～
如果不確定登入資料，可以聯絡研究團隊協助你。
```

### 9. 服務暫時無法連線

```text
目前服務暫時連不上，請稍後再試一次。
若持續無法使用，可以聯絡研究團隊協助你，謝謝你的耐心～
```

## 實作來源

文案集中在 supabase/functions/nsysu-line/messages.json，由雲端 messages.mjs 與本機 backend/nsysu/line_messages.py 共用。修改後的新事件／新提醒使用新文案；歷史已送出訊息不改寫。

現行無圖片、無標題的 Buttons template 文字上限為 160 字；本次範例綁定測試 104 字、09:00 提醒 93 字、後續提醒 88 字，均保留帳號與日期。依據 [LINE 官方訊息規格](https://developers.line.biz/en/reference/messaging-api/#buttons)。

驗證輸出位於 artifacts/line-message-copy；使用隔離 PostgreSQL、SQLite 及模擬 LINE transport，不接正式收件人。
